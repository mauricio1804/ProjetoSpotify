# 🎵 Spotify Clone

Projeto desenvolvido para a disciplina de **Interfaces Web**, com o objetivo de reproduzir a interface do Spotify utilizando tecnologias de desenvolvimento front-end.

O projeto consiste em um clone visual da página inicial e da tela de login do Spotify, aplicando conceitos de HTML, CSS, Bootstrap e design responsivo.

---

## 📸 Visão Geral

O sistema simula a experiência visual do Spotify, apresentando:

* Página inicial inspirada no site oficial;
* Barra de navegação responsiva;
* Seção principal com destaque para conteúdos musicais;
* Carrossel de apresentação;
* Tela de login personalizada;
* Layout adaptável para diferentes dispositivos.

---

## 🚀 Funcionalidades

### 🏠 Página Inicial

* Navbar responsiva;
* Menu de navegação com opções:

  * Premium
  * Ajuda
  * Baixar
  * Inscrever-se
  * Entrar
* Carrossel de destaque;
* Botões de chamada para ação;
* Layout inspirado na identidade visual do Spotify.

---

### 🔐 Tela de Login

* Interface de autenticação inspirada no Spotify;
* Botões para login utilizando:

  * Facebook
  * Apple
  * Google
* Campos de acesso estilizados;
* Layout centralizado e responsivo.

## ▶️ Como Executar

1. Clone o repositório:

```bash
git clone https://github.com/mauricio1804/ProjetoSpotify.git
```

2. Acesse a pasta do projeto:

```bash
cd ProjetoSpotify
```

3. Abra o arquivo `index.html` em qualquer navegador.

Não é necessária nenhuma instalação adicional.
